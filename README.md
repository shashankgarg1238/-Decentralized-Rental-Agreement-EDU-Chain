# NeoFashion - Futuristic Clothing Store 🛍️✨

## 🧾 Project Description
**NeoFashion** is a decentralized futuristic clothing store built on blockchain technology. This revolutionary e-commerce platform combines cutting-edge smart contract functionality with a stunning cyberpunk-inspired interface, offering users a secure, transparent, and immersive shopping experience for next-generation fashion items.

## 🌐 Project Vision
Our vision is to **revolutionize online fashion retail** through blockchain technology and futuristic design. We aim to create a trustless shopping ecosystem where customers can purchase innovative clothing items with complete transparency, automated transactions, and a user experience that feels like shopping in the year 2050.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v14 or higher)
- **MetaMask** browser extension
- **Modern Web Browser** (Chrome, Firefox, Edge)
- **Ethereum Testnet ETH** for transactions

### Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/shashankgarg1238/-Decentralized-Rental-Agreement-EDU-Chain.git
   cd -Decentralized-Rental-Agreement-EDU-Chain
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Development Server**
   ```bash
   npm start
   # or
   npm run dev
   ```

4. **Open Your Browser**
   Navigate to `http://localhost:3000`

### 🔧 Smart Contract Deployment

1. **Deploy the Contract** (using Remix IDE):
   - Open [Remix Ethereum IDE](https://remix.ethereum.org/)
   - Create `ClothingStore.sol` file
   - Copy code from `contract/ClothingStore.sol`
   - Compile with Solidity 0.8.0+
   - Deploy using MetaMask to your preferred testnet

2. **Update Configuration**:
   - Copy the deployed contract address
   - Update `CONTRACT_ADDRESS` in `app.js`
   - Refresh the application

## 🎮 How to Use

### 1. **Connect Your Wallet** 🔐
- Click "Connect Wallet" in the top navigation
- Approve MetaMask connection
- Your address and balance will be displayed

### 2. **Browse Products** 👕
- View our futuristic clothing catalog
- Filter by category (Jackets, Pants, Accessories, etc.)
- Sort by name or price
- Click any product for detailed view

### 3. **Add to Cart** 🛒
- Click on a product to open details modal
- Select quantity (respects stock limits)
- Click "Add to Cart"
- Watch your cart counter update

### 4. **Manage Your Cart** 📝
- Navigate to "Cart" section
- Adjust quantities using +/- buttons
- Remove items individually
- View real-time total calculation

### 5. **Make a Purchase** 💳
- Review your cart items and total
- Click "Purchase Now"
- Confirm transaction in MetaMask
- Wait for blockchain confirmation
- View order in "Orders" section
